# Neon Relic

A futuristic 2D platformer prototype built using HTML5, CSS, JavaScript and Phaser.js as part of an AI + Game Development practical assignment.

## About the Game

Neon Relic is a 2D platformer where players explore three futuristic chambers, collect energy crystals, avoid hazards and unlock portals to progress through the game.

Players must collect the required crystals in each chamber before reaching the exit portal. Each chamber introduces a different platform layout and obstacle arrangement, creating a progressively challenging experience.

## Features

- Three playable chambers.
- Platform movement and jumping.
- Crystal collection objectives.
- Spike hazards and collision detection.
- Portal-based chamber progression.
- Pause and resume functionality.
- Keyboard controls for desktop.
- On-screen touch controls designed for mobile.
- HUD displaying chamber information and crystal progress.
- Futuristic neon-inspired visual design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Phaser.js

## Controls

| Action | Controls |
|---|---|
| Move left | A / Left Arrow |
| Move right | D / Right Arrow |
| Jump | Space / W / Up Arrow |
| Pause | Escape |
| Mobile movement | On-screen buttons |
| Mobile jump | On-screen jump button |

## How to Play

1. Start the expedition.
2. Navigate through the platforms.
3. Collect the required energy crystals.
4. Avoid spike hazards.
5. Reach the portal once the required crystals are collected.
6. Complete all three chambers.

## Levels

| Level | Chamber | Crystal Requirement |
|---|---|---|
| 1 | The Awakening | 3 |
| 2 | The Sunken Hall | 4 |
| 3 | The Core | 5 |

## Running the Game Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The game can also be run using a local development server such as VS Code Live Server.

## AI-Assisted Development

ChatGPT was used to assist with game concept development, gameplay implementation, code generation, debugging and rapid prototyping.

The game mechanics, code and interactions were tested through browser-based gameplay.

The visual elements in the current prototype are primarily generated programmatically using Phaser graphics and textures.
